# Verify-OTP-Option

Developed a frontend OTP Generator using HTML, CSS, and JavaScript that generates a random 4- or 6-digit verification code. Implemented dynamic UI updates, button click events, and JavaScript random number generation to simulate the OTP generation process for learning and demonstration purposes.
